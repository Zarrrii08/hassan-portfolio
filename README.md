# Muhammad Hassan — Portfolio

A responsive portfolio based on the supplied Carrd reference, with compact desktop and mobile layouts, accessible social/contact links, a dark purple theme, subtle background particles, and staggered entrance animations that respect reduced-motion preferences.

## Local preview

Run `python -m http.server 3000 --directory dist` from this folder and visit http://localhost:3000. No installation or build is required.

## Files

- `dist/index.html`: profile, metadata, social links, CV and contact destinations
- `dist/styles.css`: responsive layout, colors and animations
- `dist/assets/images/image01.jpg`: portrait

## Profile and deployment

The portfolio uses Muhammad Hassan's supplied portrait, social links, CV, email and Pakistan phone number (+92 330 9145816).

Netlify serves the `dist` folder using `netlify.toml`. No build command is needed.
